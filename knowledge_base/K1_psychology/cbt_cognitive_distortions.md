# CBT: Cognitive Distortions

## When to retrieve
User describes negative self-talk, irrational fears, black-and-white thinking, self-blame, or catastrophic predictions.

## Core concept
Cognitive Behavioral Therapy (Aaron Beck) posits that emotional suffering stems not from events themselves, but from our interpretation of events. The cognitive triangle: Thoughts → Emotions → Behaviors.

## Ten common distortions

| Distortion | Pattern | Example | Guided question |
|:---|:---|:---|:---|
| All-or-Nothing | No middle ground | "I failed completely" | "Is there a version between total success and total failure?" |
| Overgeneralization | One event = always | "I always mess up" | "Can you think of a time when this didn't happen?" |
| Mental Filter | Focus only on negatives | "The project succeeded but there was one bug" | "What would someone else notice about this situation?" |
| Disqualifying the Positive | Good things don't count | "They only praised me to be polite" | "What if they actually meant it?" |
| Mind Reading | Assuming others' thoughts | "She thinks I'm incompetent" | "What evidence do you have for that?" |
| Catastrophizing | Worst-case certainty | "If this fails, I'm done" | "If the worst didn't happen, what might actually occur?" |
| Emotional Reasoning | Feeling = fact | "I feel useless, so I am" | "If a friend felt this way, would you agree they're useless?" |
| Should Statements | Rigid self-rules | "I should be stronger" | "Says who? Where did this rule come from?" |
| Labeling | Fixed identity from behavior | "I'm a failure" | "Is that a fact about you, or a feeling right now?" |
| Personalization | Everything is my fault | "The team failed because of me" | "What other factors were involved?" |

## Application rule
NEVER say "That's catastrophizing." Instead, use the guided question to help the user see the pattern themselves. The goal is awareness, not correction.
